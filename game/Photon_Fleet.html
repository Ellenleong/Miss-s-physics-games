老師設定：Google Sheets 成績接收
  1. 在目標試算表選「擴充功能 → Apps Script」。
  2. 另行開啟 Photon_Fleet_Google_Sheets.gs，將內容全部貼上取代原本程式並儲存。手動執行一次 setup，完成授權。
  3. 「部署 → 新增部署 → 網頁應用程式」：執行身分選自己；存取權選「所有人」。
  4. 複製以 /exec 結尾的網址，貼到下方並儲存。更新程式時請「管理部署 → 編輯 → 新版本」。
  5. 先用測試姓名完成一次，確認結果顯示「已確認寫入 Google Sheets」。如學校帳戶禁止匿名存取，需管理員允許此部署設定。

此設定只保留在目前瀏覽器。要預先設定所有學生使用的檔案，可在 HTML 搜尋 SHEET_WEB_APP_URL 並填入部署網址。上傳需連網；遊戲本身可離線執行。記錄：日期、開始時間、結束時間、遊戲時長（秒）、分數、姓名、班別、學號、重新開始次數，另加答對題數、原始分數、時間係數、紀錄 ID 與完成狀態。未完成的嘗試不會送出。
